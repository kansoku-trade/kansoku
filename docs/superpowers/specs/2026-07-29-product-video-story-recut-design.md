# 产品视频改版：一次判断的故事线（v2）

日期：2026-07-29。基于 `apps/video/` 现有 84.47 秒母版（九章功能巡礼）改版。

## 背景与目标

首要投放场景确定为 **X / 社交时间线**：默认静音自动播放，前 3 秒决定观众滑不滑走，完播甜区 45–60 秒。

现版三个问题：

1. 单章信息密度超载——9 章塞 84 秒，同屏最多四层文字（章标题 + 右上副标题 + 叠加卡 + 截图里 App 自己的文字）。
2. 句式单一——十一句主标题全是理念对仗句，部分要转弯才懂。
3. 流程是功能清单，不是故事——没有「一个人怎么用它完成一次判断」的主线。

另有三处布局问题：03/07/08 章的叠加卡没有设显式高度，边框只包住一行、文字互叠，03 的卡还压在 App 自己的清单上（04 章巡检卡用了 `layout={false}` + 显式宽高，是正常的参照实现）。

改版目标：**总长 62 秒左右，按「盘前 → 盘中 → 收盘后」的使用顺序重排成故事线，每屏最多两层文字，功能覆盖一个不减**（用户红线：不得退回简单版）。

## 视觉与节奏规格

- 每屏最多两层叠加文字：一句主句（字号从现在的 50 提到 64 左右）+ 一排 Pill 或一行小字。**删除右上角副标题层。**
- 开场不再有纯文字论点屏和独立品牌屏；第一帧就是产品画面。品牌定位句「运行在你 Mac 上的个人研究工作台」挪到结尾品牌卡。
- 左上 mono 章节标签保留，改为上表的节拍标签。
- 转场维持 0.35–0.45s 交叉淡化；截图镜头维持现有缓推运动。
- 背景音乐 `observed-path.mp3` 与音量参数不变（静音播放为主，音乐服务开声音的少数人）。
- 每句主句停留 ≥ 2.5s，保证静音刷时间线读得完。

## 叠加卡处理（同时消灭布局 bug）

- **删除** `sepaCard`、`providerCard`、`trainerCard`——三张卡与 App 截图内容重复且布局有 bug，信息全部并入 Pill 层。
- **保留** `followCard`（32–40s 的核心信息载体，`layout={false}` + 显式宽高，布局已验证）。
- `localFlow` 四卡链路图保留，底部长句压缩为一行以内。

## 验收标准

1. 总时长 62 ± 3 秒；ffprobe 维持 1920×1080 / 30fps / H.264 / AAC 双声道。
2. 每个节拍中点抽帧检查：同屏叠加文字 ≤ 2 层，无叠字、无截断、无叠加元素压住 App UI 文字。
3. 静音完整可读：逐帧确认每句主句完整停留 ≥ 2.5s。
4. 定位红线：全片无收益承诺、无「自动交易」表述；结尾维持研究工作台定位与 `kansoku.trade` CTA。
5. 输出 MP4 继续被 `apps/video/.gitignore` 忽略。
