# Kansoku 产品定位

日期：2026-07-28
状态：已确认

## 为什么现在要定

做新版落地页的时候撞墙了：hero 主张连做两版都不对。往回查才发现根子不在文案——**这个产品从来没定过定位**。

全仓扫下来，八个地方八种说法：

| 位置 | 现在写的 |
| --- | --- |
| `README.md:7` | 装在你 Mac 上的 **AI 看盘搭子** |
| `README.md:2`（banner alt） | 本地优先的 AI 看盘与研究桌面应用 |
| `apps/site/src/pages/index.astro:96`（title） | 陪你走完每一个交易日的 AI 看盘搭子 · 本地优先 macOS 看盘应用 |
| `apps/site/src/pages/index.astro:97`（description） | **本地优先的 AI 看盘应用** |
| `apps/site/src/pages/index.astro:102`（h1） | **陪你走完每一个交易日** |
| `apps/site/public/llms.txt:3` | **本地优先的 AI 看盘 macOS 应用** |
| `apps/site/src/pages/about.astro:7,15` | 本地优先 AI 看盘 macOS 应用 |
| `package.json:5` | Personal US market observatory with trading records, agent skills… |

三个问题：

1. **这些全是「品类定义」，不是主张。**「本地优先的 AI 看盘应用」回答的是"这是什么"，不回答"我为什么要用它"。
2. **唯一像 slogan 的「陪你走完每一个交易日」只活在首页一处**，README、`llms.txt`、关于页都没有——它是写首页那天顺手写的，没被当成定位定下来。
3. **出现频率最高的是「本地优先」，八处占四处**，事实上成了当前定位核心。但它是及格线不是卖点（见下）。

另外 `package.json` 那句英文是仓库还是个人交易日志时期的遗留，产品化后没同步。

## 目标用户

不是「散户」。产品的硬门槛已经把人筛得极窄：

- macOS 且 Apple Silicon
- 装并登录 longbridge CLI（长桥用户盘 = 做港美股的中文用户）
- 自己配 AI key，或本机有 codex 登录态
- 应用无付费签名，首次打开要右键 →「打开」
- 界面全中文，分发走 GitHub Releases 而不是 App Store
- 内置 SEPA 趋势模板、缠论、MACD 背驰——看得懂才用得上

再叠上作者本人的使用痕迹（`journal/` 是 git-ignored 用户数据，2026-07-23 至 07-27 共 4 篇，样本薄）：全部是**短线、日内、多周期重评**，且自动小结里有「当日记分板」和「当日 AI 花费」两个小节。

**画像：懂技术的中文散户，用长桥做美股短线，Mac 用户，自己配 AI key，已有技术分析底子，在乎自己判断准不准、也在乎 AI 花了多少钱。**

说白了就是「程序员炒股」这群人。

## 定位陈述

内部用，不是对外 slogan：

> 给**用长桥做美股短线、不信黑箱的技术型散户**的 AI 看盘应用。
> 别的 AI 给你一个结论；Kansoku 给你一个**能查账的判断**——每句话有出处，归档后不许改口，事后按命中率记分。

## 三根支柱

每条都有产品事实撑着，不是形容词：

| 支柱 | 产品事实 |
| --- | --- |
| **有出处** | 工具调用全程留痕，点开就是它查了什么；指标全部本机 TypeScript 实算，不是某个 API 甩回来的数字；AI 先读你画的线再回答 |
| **不改口** | 归档的预测是冻结记录，追问只解释、不改写；三档情景概率合计 100%、每档挂触发条件，写死了就赖不掉 |
| **有战绩** | 判断与结果追踪、历史命中率、当日记分板；AI 花了多少钱记在你自己账上 |

**「本地优先」的正确位置是支柱的实现手段**，不是主张。有出处的前提是数据和算法在你手上——它继续出现在页面下半部和文档里，但不再当头条。

理由：目标人群是开发者，听到「数据不上传」的反应是"那不然呢"。对他们这是及格线，不是加分项。拿它当 hero 主张等于把及格线当成绩。

## 对外文案

- **品类定义**：能查账的 AI 看盘搭子
- **Slogan（hero 大字）**：它说的每句话，你都能查。
- **备用小标题**（段落级）：判断留痕。结论记分。

## 明确不卖什么

- 不卖「AI 帮你赚钱」、荐股、买卖信号
- 不卖「本地优先」当主张
- 不卖「数据最全」——数据来自长桥，不构成差异化
- 不卖长线价值投资——产品实际服务的是短线多周期
