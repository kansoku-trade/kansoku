# 对话过程按时间平铺

日期：2026-09-06
状态：已确认
范围：三类 AI 对话共用的 `presentTranscript` 时间轴。只改 `apps/web` 对话展示。

## 背景

连续工具现在会收成「N 个工具」。完成后套进「跑了 xx 秒」里，点开还要再点一次组。生成中组默认只露正在跑的那条，已完成的被藏掉。这和「思考 + 工具是一条时间轴」不一致。

已确认选 C：完成和生成中都平铺。

## 规则

思考过程、每一条工具、中间那些过程文字，按发生顺序一条条排。不再出现「N 个工具」这一层。

- **生成中**：已完成的带勾，正在跑的带点，全都看得见。
- **完成后**：这些内容仍收在「跑了 xx 秒」里。点开就是整条时间轴。没有工具的一轮仍然没有「跑了」。
- **原始请求 / 响应**仍默认收着，要点那一条才展开。
- **思考过程**完成后在「跑了」里面（已落地）；生成中仍跟工具排在同一条轴上，不另做组。

## 改哪里

`presentTranscript.ts` 的 `emitTools` / `groupSequence`：连续工具不再收成 `tool-group`，每条都是 `type: 'tool'`。

`presentTranscript` 不再产出 `tool-group` 后，删掉 `TranscriptBlockView` 的对应分支和 `ToolGroupRow`。类型里的 `tool-group` 一并去掉。

折叠键继续用 `tool:${tool.id}`。不再依赖 `group:…`。

## 测例

`presentTranscript.test.ts` 里凡是 `group:N:…` 改成一条条 `tool:…`。

`ConversationTranscript.test.tsx`：

- 生成中不再断言「2 个工具，进行中」；已完成的工具标题也要看得见。
- 点开「跑了」后，组头「N 个工具」不再出现，各条工具标题直接在。
- 保折叠的测例若还用 `group:lt1`，改成某一条 `tool:lt1`。

## 不做的事

- 不改后端落盘。
- 不把原始 JSON 默认摊开。
- 不把「跑了 xx 秒」这层外折去掉。
- 不改输入框、滚动、session 切换仓库。

## 验证

1. 单测：完成轮次和 live 轮次都不再产出 `tool-group`。
2. 点开「跑了」能直接看到每条工具和思考过程，无需再点「N 个工具」。
3. 生成中同时能看到已完成和正在跑的工具行。
